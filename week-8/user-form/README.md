## 📖 About the Project

This is a **React Registration Form App** built to demonstrate key concepts of **controlled components**, input handling, form validation, and clean UI feedback.

Developed as part of the **AUTOWAVE Week 8 Intern Training**, it showcases modern best practices in React form development, styled with Tailwind CSS.

### ✅ Key features include

- Controlled inputs using `useState`
- Real-time validation for Name, Email, Password, Confirm Password
- Submit button only enabled when validation passes
- Accessible form with semantic HTML and ARIA where needed
- Clean, responsive design using Tailwind CSS `v3.4.17` + PostCSS `v8.5.5`
- Deployed globally via Cloudflare Pages
- Footer with Joseph Ogbole’s social links

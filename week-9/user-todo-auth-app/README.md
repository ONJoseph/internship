## 📖 About the Project

A fully responsive Todo application demonstrating the power of React Context API combined with `useReducer` for shared global state.

Developed as part of the **AUTOWAVE Week 8 Intern Training**, it showcases modern best practices in the use of React Context API, styled with Tailwind CSS.

### ✅ Key features include

- 🔐 Simulated User Authentication (Login/Logout)
- 📝 Full Todo CRUD
- 💾 Persistent State (localStorage)
- 🌙 Theme Toggle (Light/Dark)
- ⚛️ Context API + useReducer
- 💅 Tailwind CSS Styling
- ☁️ Deployed with Cloudflare Pages

## 💻 Getting Started

### 🧰 Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)
- [VS Code](https://code.visualstudio.com/)

---

### 🔧 Setup

```bash
# Clone the repository
git clone https://github.com/ONJoseph/internship.git

# Navigate to the project folder
cd internship/week-9/user-todo-auth-app

# Checkout the week8 branch
git checkout week9

## 📦 Install Dependencies
- npm install

## 🚀 Run Locally
- npm run dev
- Visit http://localhost:5173 in your browser.

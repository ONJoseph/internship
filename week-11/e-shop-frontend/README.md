## 📖 About the Project


E-Shop Frontend is a mini e-commerce platform built as the AUTOWAVE Week 11 Capstone Project, integrating everything learned from Weeks 1–10.

This app demonstrates React mastery: authentication, routing, cart system, search & filter, responsive UI with Tailwind, and deployment with Cloudflare Pages + GitHub Actions CI/CD.

### ✨ Key Features

- 🔐 **Authentication (Mocked)** — Login & Signup forms with local state and validation.  
- 🛍️ **Product Listing** — Fetch products from Fake Store API or mock JSON.  
- 📄 **Product Details Page** — View full details of a selected product.  
- 🛒 **Cart System** — Add/remove items, manage quantities, and display total.  
- 🔎 **Search & Filter** — Search bar + category filters.  
- 🎨 **Responsive Design** — Styled with **Tailwind CSS v3.4.17** for a modern UI/UX.  
- ⚡ **Deployment** — CI/CD pipeline using **GitHub Actions** + **Cloudflare Pages**.

## 💻 Getting Started

### 🧰 Prerequisites

Ensure you have the following installed:

- Git

- Node.js v20.19.0+

- VS Code

## 🔧 Setup

# Clone the repository
- git clone https://github.com/ONJoseph/internship.git

# Navigate to the project folder
- cd internship/week-11/e-shop-frontend

# Checkout the week11 branch
- git checkout week11

## 📦 Install

- npm install

## 🚀 Usage

# Run locally
- npm run dev

# Build for production
- npm run build

# Preview production build
- npm run preview

- Visit 👉 http://localhost:5173
 in your browser.
